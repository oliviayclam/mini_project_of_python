mini_project_of_python

This project collects multiple small Python systems built as learning exercises and demos. Each system is contained in a directory under PythonTestProject/. The site provides documentation, run instructions, and links to each system's source files.

How to run a system

  1. Clone the repository: git clone https://github.com/oliviayclam/mini_project_of_python.git
  2. Change into the system directory (example): cd PythonTestProject/OliviaPortal
  3. Install dependencies if required: pip install -r requirements.txt
  4. Run the main program (example): python main.py
