# Yum Cha Merge / 點心合合樂

Cute Hong Kong dim sum merge game in the browser (React, no Vite).

## Play

```bash
cd DimSumMerge
npm install
npm start
```

Opens http://localhost:3000

1. Pick mood: Chill 茶 / Normal 點心 / Spicy 辣
2. Waitress asks **幾多位？** then **飲咩茶？**
3. Merge two same steamers, deliver dishes onto order tickets
4. **對決 Battle** for mini-games vs NPC (or they pop up after orders)

Mute and pause are on the top bar for streams.
